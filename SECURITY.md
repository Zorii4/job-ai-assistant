# Безопасность публичного репозитория

Этот репозиторий может быть опубликован. В него не добавляются:

- рабочие тексты prompt и внутренние сценарии агентов;
- API keys, токены, пароли, cookies и private keys;
- реальные или рабочие резюме, вакансии, заметки, результаты AI и контрольные данные;
- локальные документы владельца проекта.

Перед коммитом запустите:

```sh
npm run check:public-safety
```

Для локальной автоматической проверки один раз включите hook:

```sh
git config core.hooksPath .githooks
```

`.gitignore` не является защитой от `git add -f` и не проверяет содержимое файлов. Автоматическая проверка ловит запрещённые пути и распространённые форматы секретов, но не заменяет ручной review.

Если закрытый материал попал в коммит, немедленно отзовите скомпрометированные секреты и перепишите все затронутые Git refs. Простое удаление следующим коммитом не очищает историю.
